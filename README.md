# algar

Landing page estática da Algar Fibra Rápida — parceiro autorizado Algar Telecom.

## Conteúdo

- `index.html` — página única com HERO, planos, depoimentos, FAQ e captura de lead
- `scripts.js` — i18n, consulta de CEP (ViaCEP + Nominatim), cobertura, FAQ accordion, captura de lead via FormSubmit, botão flutuante WhatsApp
- `coverage.js` — polígonos da área de cobertura
- `assets/` — imagens e logo

## Deploy

Sobe os arquivos pra qualquer servidor estático ou ativa GitHub Pages na branch `main`.
